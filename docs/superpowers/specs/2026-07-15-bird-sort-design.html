🐦 Bird Sort — Design Spec

Date: 2026-07-15 · Platform: React Native (Expo + TypeScript) · Status: proposed

1. Concept

Bird Sort is a single-screen sorting puzzle. Birds sit on branches. The player picks up the top run of same-species birds from one branch and drops them on another. When a branch holds a full set of one species, that branch locks and the birds do a happy dance (they do not fly away). The level is won when every branch is either empty or a locked, sorted set.

2. Core Rules

  • Board: N branches. Each branch holds up to capacity birds (v1: 4).
  • Move: tap a source branch to pick up its top group (all consecutive same-species birds from the top), then tap a destination.
  • Legal destination: empty branch, OR a branch whose top bird is the same species AND has room. The group is capped by available space.
  • Solve: a branch full of one species locks — birds happy-dance in place, branch turns green, can no longer be picked from.
  • Win: every branch is empty or locked-solved.

3. Data Model

type Species = number;        // index into ROSTER
type Branch  = Species[];     // index 0 = base (bottom), last = top
type Board   = Branch[];

4. Game Logic — game.ts (pure, no React)

All rules live in pure functions so they are unit-testable without rendering.

FunctionPurpose
generateLevel(species, capacity, extra)Build a solved board, then reverse-shuffle by legal single-bird moves → always solvable.
topGroup(branch)Count of same-species birds on top of a branch.
canMove(board, from, to)True if the move is legal (not locked, dest empty or matching + has room).
applyMove(board, from, to)Return a new board with the top group moved (capped by dest space). Immutable.
isCleared(branch)Full and all one species → solved/locked.
isWon(board)Every branch empty or cleared.

Known regression to guard

Earlier prototype bug: applyMove called topGroup(from) passing the branch index instead of the branch array, so it moved 0 birds. Unit test must assert a legal move actually relocates the whole top group.

5. Bird Roster (data-driven)

Roster is a data table. Each species = a distinct SVG path + palette. Adding "every type of bird" over time is one row each — no engine changes, no redraw of existing birds.

7. Interaction Flow

  1. Tap branch with movable birds → selected (branch lifts, top group highlighted).
  2. Tap same branch → deselect.
  3. Tap another branch → if canMove, apply move; else reselect that branch (if movable).
  4. If the moved-to branch becomes solved → lock it, run happy-dance loop.
  5. If isWon → show win overlay with "Next level".

8. Animation

  • Select: branch translateY up, top bird scales up.
  • Happy dance: looping bounce + rotate on each bird in a solved branch, staggered per bird for a wave.
  • Use React Native Animated (or Reanimated if a loop needs to be smooth). No new heavy dep unless measured need.

9. Levels & Difficulty

  • Procedural, guaranteed solvable (build solved → reverse-shuffle via legal moves).
  • Species count scales with level number; capacity fixed at 4; 2 extra empty branches.

10. Chrome

  • Move counter (top).
  • Undo (revert last move via history stack), Restart (reset current board), Next level (after win).

11. Testing

  • Unit tests on game.ts: legal-move relocates full top group (regression), illegal moves rejected, locked branches immovable, isWon correctness, generateLevel output is solvable.

12. Out of Scope (YAGNI)

Persistence / save state · sound · accounts · hints · level select · leaderboards. Add later only if wanted — none block the core loop.
